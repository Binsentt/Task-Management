# Railway Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy the monorepo as working frontend and backend services in a new Railway project, with Atlas MongoDB, production CORS/cookies, REST, WebSocket, and verified public domains.

**Architecture:** Keep the existing Express service as the backend and deploy it from the repository root using `railway.json`; it serves both `/api` and authenticated `/ws`. Add a dependency-free Node static server to the `Task` workspace so the Vite build can run as an independent Railway service with SPA fallback. Provision the backend first, inject secrets and production URLs, then build the frontend against the backend domain and finish with cross-origin verification.

**Tech Stack:** Railway CLI/MCP, Node.js 20+, npm workspaces, Express 5, `ws`, MongoDB Atlas, React 19, Vite 8.

## Global Constraints

- Use a new Railway project; do not alter or reuse an existing project.
- Store `MONGODB_URI` and `JWT_SECRET` only as Railway backend variables; never commit or print them.
- Use the supplied Atlas URI as `MONGODB_URI`.
- Set `NODE_ENV=production` and `COOKIE_SAMESITE=none`.
- Keep exactly one backend replica because WebSocket connections are process-local.
- Leave SMTP unset and do not claim password-reset email delivery is available.
- Do not report deployment success until Railway reports `SUCCESS` and public checks pass.
- Frontend variables must contain only public HTTPS/WSS URLs.
- Run backend tests, frontend tests, and frontend production build before provisioning.

- [ ] **Step 3: Implement `Task/server.js`**

Implement a dependency-free `node:http` server that:

```js
import { createReadStream } from 'node:fs';
import { stat } from 'node:fs/promises';
import { createServer } from 'node:http';
import { extname, join, normalize, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';

const root = resolve(fileURLToPath(new URL('./dist', import.meta.url)));
const port = Number(process.env.PORT || 4173);

const contentTypes = {
  '.css': 'text/css; charset=utf-8',
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.svg': 'image/svg+xml',
  '.png': 'image/png',
  '.ico': 'image/x-icon',
};

function safePath(urlPath) {
  const decoded = decodeURIComponent(urlPath.split('?')[0]);
  const candidate = normalize(join(root, decoded));
  return candidate.startsWith(`${root}/`) || candidate === root ? candidate : null;
}

async function fileExists(path) {
  try {
    return (await stat(path)).isFile();
  } catch {
    return false;
  }
}

const server = createServer(async (request, response) => {
  try {
    const requested = safePath(request.url || '/');
    const asset = requested && await fileExists(requested) ? requested : join(root, 'index.html');
    if (!(await fileExists(asset))) {
      response.writeHead(503, { 'content-type': 'text/plain; charset=utf-8' });
      response.end('Frontend build is unavailable');
      return;
    }
    response.writeHead(200, {
      'content-type': contentTypes[extname(asset)] || 'application/octet-stream',
      'cache-control': asset.endsWith('index.html') ? 'no-cache' : 'public, max-age=31536000, immutable',
    });
    createReadStream(asset).on('error', (error) => {
      response.destroy(error);
    }).pipe(response);
  } catch (error) {
    response.writeHead(400, { 'content-type': 'text/plain; charset=utf-8' });
    response.end(error instanceof URIError ? 'Invalid URL' : 'Request failed');
  }
});

server.listen(port, '0.0.0.0', () => {
  console.log(`Frontend listening on 0.0.0.0:${port}`);
});
```
